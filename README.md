# Digital Safety Hub

Build the complete modern, professional, responsive “Cyber Awareness & Digital Safety” website specified in the attached brief. Implement the requested navigation, pages/sections, educational content, quiz, incident guidance, cybersecurity visual direction, accessibility, and polished responsive interactions.

CyberSafe is a modern, responsive Cyber Awareness & Digital Safety website designed to help users identify cyber threats, recognize scams, protect privacy, and build safer digital habits with guides, interactive tools, checklists, and safety checkups.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
